Website CYBER-HEAT mengambil tema CYBERPUNK dengan fokus mobil-mobil dengan nuansa neon.
Website ini terdiri dari beberapa halaman, yaitu:
1. Dashboard => Laman pertama ketika user mengakses website
2. Sign Up => Laman ketika user ingin membuat akun baru
3. Sign In => Laman ketika user ingin masuk dengan akun yang sudah ada di dalam database
4. Pilih Side => Laman user memilih side antara Street Racer atau Police
5. Street Racer Garage => Laman yang dapat diakses ketika user memilih Street Racer
6. Police Garage => Laman yang dapat diakses ketika user memilih Police
